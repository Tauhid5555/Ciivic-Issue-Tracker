## How to read these

These use a simplified ASCII convention:

- `═══` = primary button or strong border
- `───` = hairline divider or secondary border
- `▓▓▓` = filled block (photo placeholder, large content)
- `░░░` = soft fill (background, muted text)
- `( )` = radio / checkbox
- `[ ]` = input field
- `[BUTTON]` = labeled button
- `►` = pointer / arrow
- Status colors are represented as text labels in [brackets] — color the actual mockup using design tokens.

Viewport: 375px (mobile) or 1280px (desktop). Markdown wraps fluidly but the structure holds.
